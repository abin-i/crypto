Exp No:2  CREATE AND DEPLOY A BLOCKCHAIN NETWORK USING HYPERLEDGER FABRIC JAVA SDK
Date:

Aim:
To create and deploy a blockchain network using Hyperledger Fabric Java SDK, initialize a channel, install and deploy chaincode, and perform invoke and query operations.

Software Requirements:
• Docker
• Java JDK
• Maven
• Hyperledger Fabric
• Hyperledger Fabric Java SDK
• Hyperledger Fabric samples

Procedure:
1. Start the Hyperledger Fabric test network.
2. Create a blockchain channel.
3. Join the peer to the channel.
4. Deploy chaincode.
5. Initialize the ledger.
6. Invoke a transaction.
7. Query the blockchain ledger.

Step 1: Start the Fabric test network
cd fabric-samples/test-network
./network.sh up createChannel

Step 2: Deploy chaincode
./network.sh deployCC \
  -ccn basic \
  -ccp ../asset-transfer-basic/chaincode-go \
  -ccl go

Step 3: Query the ledger
export PATH=${PWD}/../bin:$PATH
export FABRIC_CFG_PATH=${PWD}/../config/
export CORE_PEER_TLS_ENABLED=true
export CORE_PEER_LOCALMSPID=Org1MSP
export CORE_PEER_ADDRESS=localhost:7051
export CORE_PEER_MSPCONFIGPATH=${PWD}/organizations/peerOrganizations/org1.example.com/users/Admin@org1.example.com/msp
export CORE_PEER_TLS_ROOTCERT_FILE=${PWD}/organizations/peerOrganizations/org1.example.com/peers/peer0.org1.example.com/tls/ca.crt

Query all assets:
peer chaincode query \
  -C mychannel \
  -n basic \
  -c '{"function":"GetAllAssets","Args":[]}'

Step 4: Invoke a transaction
peer chaincode invoke \
  -o localhost:7050 \
  --ordererTLSHostnameOverride orderer.example.com \
  --tls \
  --cafile "${PWD}/organizations/ordererOrganizations/example.com/orderers/orderer.example.com/msp/tlscacerts/tlsca.example.com-cert.pem" \
  -C mychannel \
  -n basic \
  -c '{"function":"CreateAsset","Args":["asset6","blue","20","Tom","500"]}'

Step 5: Query the created asset
peer chaincode query \
  -C mychannel \
  -n basic \
  -c '{"function":"ReadAsset","Args":["asset6"]}'

Expected Output:
{
  "ID": "asset6",
  "Color": "blue",
  "Size": 20,
  "Owner": "Tom",
  "AppraisedValue": 500
}

Java SDK Implementation:
Create a Maven Java project and add the compatible Fabric Gateway Java dependency. Use the Fabric Gateway Java API to connect to the peer through a configured connection profile and submit/evaluate transactions.

Example transaction logic:
Contract contract = network.getContract("basic");

byte[] result = contract.evaluateTransaction(
    "ReadAsset", "asset6"
);
System.out.println(new String(result));




Result:
Thus, a Hyperledger Fabric blockchain network is created, chaincode is deployed, and transactions are successfully invoked and queried.
